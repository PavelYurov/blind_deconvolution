blinddeconv.processing.core module

Основной модуль фреймворка обработки изображений.

Содержит класс Processing для управления конвейером обработки изображений: загрузка, фильтрация, восстановление, анализ метрик.

Авторы: Юров П.И., Беззаборов А.А., Куропатов К.Л.

Базовые классы: object

Фреймворк для обработки изображений.

Предоставляет полный конвейер для работы с изображениями: загрузка, применение фильтров, восстановление, анализ метрик.
