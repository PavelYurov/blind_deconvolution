# Bayesian implementations

Этот раздел содержит реализации слепой деконволюции, формулируемые как байесовские модели (MAP/VB), где неизвестные резкое изображение `x` и PSF/ядро `h` оцениваются совместно из наблюдений `y`.

Обозначения (типичные для всех реализаций):

- Наблюдение: $y = h * x + n$, где $*$ — свёртка, $n$ — шум.
- `H` — оператор свёртки, соответствующий `h` (часто реализуется через FFT).
- Байесовская постановка: задаются априори на `x`, `h` и гиперпараметры (точности), далее выполняется MAP-оптимизация или вариационный Байес.

## `bbd_deip.py` — `BBD_DEIP`: differently exposed image pairs (Babacan et al., 2010)

**Математика**

Используются два изображения с разной экспозицией:

- длинная экспозиция: $y_l = Hx + n_l$ (размыто, но менее шумно),
- короткая экспозиция: $y_s = x + n_s$ (резко, но сильно шумно).

Типичная иерархическая модель:

- правдоподобие: гауссово для `y_l` и `y_s` с разными точностями `β_l, β_s`,
- априори изображения: `TV(x)` (сохранение границ),
- априори ядра: SAR/лапласиан `||Dh||^2` (гладкость),
- гамма-гиперприори на `α` (TV-вес), `γ` (ядро), `β_l`, `β_s`.

Вариационный вывод (VB) приводит к итеративным обновлениям вида «Винер в частотной области + MM/half-quadratic для TV», плюс проекция ядра на ограничения (неотрицательность и нормировка).

**Как устроен код**

- Главный класс: `BBD_DEIP`.
- `process(...)` реализует основной VB-цикл: чередование обновлений `x`, `h` и гиперпараметров.
- TV-часть: `_compute_horizontal_gradient`, `_compute_vertical_gradient`, `_compute_divergence`, `_compute_tv`.
- FFT-инфраструктура для ядра: `_pad_kernel_for_fft`, `_extract_kernel_from_padded`.
- Частотные операторы градиента/лапласиана: `_compute_gradient_operators_fft`, `_compute_laplacian_operator_fft`.
- Опциональное выравнивание пары кадров: используется `scipy.ndimage.shift` (см. импорт `image_shift`).

## `vbbid_tv.py` — `VBBID_TV`: VB blind deconvolution with TV prior (Babacan et al., 2009)

**Математика**

Одно наблюдение `y = Hx + n` (гауссов шум). Априори:
Одно наблюдение $y = Hx + n$ (гауссов шум). Априори:

- изображение: `TV(x) = Σ_i √((∇_h x_i)^2 + (∇_v x_i)^2 + ε)`,
- ядро: SAR/лапласиан `||Dh||^2`,
- гамма-гиперприори для точностей `α_im`, `α_bl`, `β`.

Используется TV в виде:

$$
TV(x) = \sum_i \sqrt{(\nabla_h x_i)^2 + (\nabla_v x_i)^2 + \varepsilon}
$$

TV недифференцируемо, поэтому применяется majorization–minimization / half-quadratic: вводятся веса `u_i ≈ √(||∇x_i||^2 + ε)`, после чего подзадача по `x` становится квадратичной и решается эффективно в частотной области.

**Как устроен код**

- Главный класс: `VBBID_TV`.
- `process(...)` — внешний вариационный цикл с обновлением `x`, `h`, `α_*`, `β`.
- TV-weights: `_compute_tv_weights`, плюс операторы `∇`/`div`.
- FFT-представление свёртки и регуляризаторов: `_pad_kernel_for_fft`, `_compute_gradient_operators_fft`, `_compute_laplacian_operator_fft`.
- Проекция ядра (ограничение носителя/неотрицательность/нормировка) реализована через переход в пространственную область и обратно (IFFT/FFT).

## `sb_bid_pe.py` — `SB_BID_PE`: Sparse Bayesian BID with parameter estimation (Amizic et al., 2012)

**Математика**

Решается MAP-задача для `y = Hx + n` с невыпуклой разреживающей априори на градиенты изображения и TV/гладкостью на ядро:

- априори изображения:
  $$
  \sum_{d \in \{h,v,d1,d2\}} w(d) \sum_i \left|\Delta_i^d(x)\right|^p,\quad 0 < p < 1
  $$
- априори ядра: TV/гладкость,
- автоматическая оценка параметров (типично `α, β, γ`) и MM-подход для невыпуклой части.

MM строит квадратичную верхнюю оценку для `|t|^p`, что даёт итеративные взвешенные квадратичные подзадачи (IRLS-подобные) по `x` и `h`.

**Как устроен код**

- Главный класс: `SB_BID_PE`.
- `process(...)` реализует многомасштабный цикл (coarse-to-fine) и на каждом масштабе — чередование обновлений `x` и `h` + обновление гиперпараметров.
- Градиенты и дивергенции в 4 направлениях: `_compute_gradient_h/_v/_d1/_d2` и `_compute_divergence_*`.
- Невыпуклая ℓp-часть: `_compute_lp_prior` и вычисление весов для MM.
- Операции свёртки/регуляризаторов ускоряются через FFT (см. `_pad_kernel_for_fft` и частотные операторы).
