# Sparse implementations

Этот раздел содержит реализации, где ключевую роль играет разреженность (sparsity): либо на градиентах изображения, либо на представлении ядра/сигнала, либо через L0/ℓp-регуляризации.

## `pbtvgr.py` — `PBTVGR`: Poisson blind deconvolution with TV + L0 gradient regularizations (Dong et al., 2021)

**Математика**

Модель пуассоновского шума (через KL-дивергенцию) и комбинация регуляризаторов:

$$
\min_{h,o}\; (\lambda/2)\, KL(P(h \otimes o), g) + \|\nabla o\|_0 + \mu \, TV(h)
$$

где

$$
KL(u,g) \approx \sum_i \left(u_i - g_i \ln u_i\right)
$$

— отрицательный лог-правдоподобие для Пуассона, $\|\nabla o\|_0$ стимулирует «кусочно-постоянные» решения с резкими гранями, а $TV(h)$ обеспечивает гладкость PSF.

Оптимизация строится как расщепление переменных и альтернативная минимизация (в статье — Algorithm 1), включая:

- `h`-подзадачу через IRLS (Algorithm 2),
- `o`-подзадачу через L0-smoothing/variable splitting (Algorithm 4),
- финальную неслепую TV-деконволюцию (Algorithm 5) для улучшения качества `o`.

**Как устроен код**

- Главный класс: `PBTVGR`.
- `process(...)` реализует слепой цикл + отдельный неслепой этап (`nonblind_iter`).
- FFT-подготовка ядра: `_pad_kernel_for_fft`, `_extract_kernel_from_padded`.
- Операторы градиента в частотной области: `_compute_gradient_operators_fft`.
- Для линейных систем используется CG (`scipy.sparse.linalg.cg`) и `LinearOperator` для матвека.

## `vbc_bid.py` — `VBC_BID`: Variational Bayesian Compressive BID (Amizic et al., 2013)

**Математика**

Байесовская слепая деконволюция объединяется с идеями compressed sensing:

$$
y = \Phi H x + n
$$

В реализации для классической деконволюции обычно $\Phi = I$.

Используются априори:

- на изображение: обобщённое гауссово распределение на градиенты ⇒ невыпуклая ℓp-квази-норма (`0 < p < 1`),
- на ядро: SAR/лапласиан (гладкость),
- разреженное представление $Hx \approx Wa$ в вейвлет-базисе ($a$ — разреженные коэффициенты, $\ell_1$-регуляризация).

Внутри вариационного цикла для разделения переменных применяется ADMM: чередуются обновления `x`, `h`, `a` и дуальной переменной (см. комментарии в коде к шагам алгоритма).

**Как устроен код**

- Главный класс: `VBC_BID`.
- `process(...)` — внешний VB-цикл (итерации `outer_iters`).
- Обновление `x` решает линейную систему методом сопряжённых градиентов (`cg`) через `LinearOperator` (см. `_update_x_cg`).
- Обновление `h` — несколько шагов градиентного спуска с проекцией на симплекс (неотрицательность + нормировка) в `_update_h`.
- Разреженные коэффициенты в вейвлетах:
  - вейвлет-преобразование через `pywt`,
  - аналитическое soft-thresholding обновление `a` в `_update_a_analytic`.
