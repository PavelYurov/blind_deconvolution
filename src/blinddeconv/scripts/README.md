# Эксперименты, скрипты и данные

Здесь описаны все эксперименты, на каких наборах данных они проводились и как запустить скрипты самостоятельно.

Для Юрова, Беззаборова и Куропатова один большой пласт экспериментов и подсчетов совпадает, но есть уникальные отдельные результаты, описанные в чьих то конкретных вкр.

## Запуск экспериментов.

Для запуска скриптов потребуется следующее:

1) Python >= 3.10.10 для всего, кроме оптимизации параметров (там Python 3.12)
2) cython (сама библиотека уже указана в фреймворке и будет установлена с другими зависимостями, но она требует сама по себе C++ Build Tools, которые придется устанавливать отдельно под собственную машину (мы использовали Visual Studio Build Tools, так как проводили расчеты на Windows))
3) 2 фреймворка: [Наш](https://github.com/PavelYurov/blind_deconvolution) и [HPO](https://github.com/Coolercool47/HPO_RL)
4) установить зависимости фреймворков (см. в README самих фреймворков)
5) все скрипты и папка `/images/` находятся в корне проекта, запуск произодился оттуда.
6) собрать cython код алгоритмов. Либо для каждого алгоритма через `../{название алгоритма}_cython/build_cython.py`, либо через скрипт `scripts/build_cython/build_cython.py` собрать все файлы, но это немного дольше.

## Описание экспериментов

Эти эксперименты едины для всех алгоритмов:

- Сравнение качества восстановления на различных датасетах

    - датасеты: `Levin`, `Kohler`, `Sun`, `Set12`
    - скрипты: `run_all_dataset_{алгоритм}.py --phase 1`

- Область приминимости алгоритмов

    - датасеты: `Grid_Test`
    - скрипты: `run_all_dataset_{алгоритм}.py --phase 1`

- Качество восстановления на итерациях, ошибка оценки ядра:

    - датасеты: `log_test`
    - скрипты: `run_all_dataset_{алгоритм}.py --phase 2`

- Влияние параметров

    - датасеты: `param_grid_test`
    - скрипты: `run_all_dataset_{алгоритм}.py --phase 3`

- Скорость работы алгоритма

    - датасеты: `Complexity_test`
    - скрипты: `run_all_dataset_{алгоритм}.py --phase 1`

Дополнительные тесты:

- Сравнение методов шумоподавления

    - датасеты: `noise_1` (`noise`), `Grid_Test`
    - скрипты: `run_all_dataset_denoise.py`, `run_all_dataset_denoise_with_blur.py`

- Сравнение качества восстановления неслепых методов

    - датасеты: `anton/Grid_Test` (все без шума), `kostya/nonblind`
    - скрипты: `run_all_dataset_hbsp_nonblind.py`, `run_all_dataset_nonblind.py`

- Сравнение результатов поиска гиперпараметров

    - датасеты: `large_data_pictures`, `middle_data_pictures`
    - скрипты: `run_all_dataset_{алгоритм}_pareto_comp.py`

- Сравнение восстановления разными регуляризаторами в условиях одного метода *fbdhsgp*

    - датасеты: `kostya/priors`
    - скрипты: `run_all_dataset_fbdhsgp.py --phase 1` (настроить параметры ('prior_name': 'Log' или 'NL1' или 'MOG' или 'Lp') и набор данных (DATASETS_PHASE1 = ["priors"]))

## Исследуемые алгоритмы

Куропатов:

- dcp ("Dark Channel")
- pmp ("Patch-wise Min Pixels")
- lmgp ("Local Max Gradient")
- esm ("Enhanced Sparse Model")
- ecp ("Extreme Channel")

Юров:

- lip_gd ("TV-Logarithmic GD")
- lip_pd ("TV-Logarithmic PD") (разные методы оптимизации в lip)
- gbbid ("Reweighted Graph TV")

Беззаборов:

- hbsp ("Hyperbolic-Secant")
- fbdhsgp ("Huber Super Gaussian")
- htp ("Heavy-Tailed")
