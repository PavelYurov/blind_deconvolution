# Наборы данных

Директория содержит все наборы данных (синтетические и реальные), на которых происходила оценка качества восстановления, а также скрипты генерации этих датасетов (датасет будет таким же с точность до карты шума (не включительно))

Наборы данных базируются на четырех открытых наборах данных - Levin, Kohler, Sun, Set12 + реальные изображения из открытых источников.
Ядра искажения были взяты собственные. Рассматривались шумы: Гауссов, Пуассонов, Импульсный (Соль и перец), Розовый, Коричневый (Броуновский) - в трех интенсивностях + чистое без шума.

## Структура наборов данных

### Директории

Наборы данных расположены в следующих директориях (общая папка `images`):

- `/large_data_pictures` - набор данных для оптимизации параметров. 75 искаженных изображений, 15 оригиналов, 15 ядер. Много изображений - более честный поиск параметров, но более поверхностный - ресурсы вычисления ограничены
- `/middle_data_pictures` - аналогично предыдущему, но размер 50 изображений, а не 75. 15 оригиналов, 10 ядер. Сокращенный датасет, чтобы можно было поставить больше итераций HPO
- `/compare_data/anton` - набор данных, используемый в работе Куропатова К.Л.
- `/compare_data/kostya` - набор данных, используемый в работе Беззаборова А.А. (да, все верно. они не перепутаны)
- `/compare_data/pasha` - набор данных, используемый в работе Юрова П.И.
- `/compare_data/noise` - набор данных для визуализации работы методов шумоподавления. Отобранные изображения из следующего пункта
- `/compare_data/noise_1` - набор данных для оценки качества работы методов шумоподавления и методов оценки шума. (Для корректной работы, требуется переименовать в "noise")

### Устройство наборов данных

Для `/large_data_pictures` и `/middle_data_pictures` структура следующая:

- `/distorted` - директория с искаженными изображениями. наименования "{название оригинала}\_{название ядра}\_{название шума или пропуск}.png"
- `/ground_truth_filters` - png ядер искажения
- `/originals` - оригинальные изображения
- `/tmp/kernels_npy` - матрицы ядер в npy формате
- `dataset_design.json` — матрица эксперимента (содержит данные об использованном шуме, его уровне и метриках *blur_psnr* и *blur_ssim*).

`/compare_data/anton`, `/compare_data/kostya` и `/compare_data/pasha`
состоят из нескольких поднаборов данных, отсортированных по оригинальным изображениям (Levin, Kohler, Sun, Set12), дополнительных поднаборах (log_test, Grid_Test, Complexity_Test, param_grid_test и т.д.) для оценки качества восстановления на итерациях, устойчивости к изменениям параметров алгоритма, скорости восстановления и области приминимости, а также изображений с натуральным искажением (real{размер ядра искажения}).

Каждый поднабор имеет следующую структуру:

- `/distorted` - директория с искаженными изображениями. наименования "{название оригинала}\_{название ядра}\_{интенсивность + название шума или clean}.png"
- `/ground_truth_filters` - png ядер искажения
- `/originals` - оригинальные изображения
- `/tmp/kernels_npy` - матрицы ядер в npy формате
- `dataset_design.json` — (опционально) матрица эксперимента (содержит данные об использованном шуме, его уровне и метриках *blur_psnr* и *blur_ssim*).

для `/compare_data/noise` и `/compare_data/noise_1`:

- `/distorted` - директория с искаженными изображениями. наименования "{название оригинала}\_{интенсивность + название шума}.png"
- `/originals` - оригинальные изображения

## Скрипты гененрации датасетов

Для создания наборов данных нужно

1) папка images в корне проекта
2) скрипты генерации в корне проекта
3) указать правильные пути до набора данных (INPUT_KERNELS_DIR, INPUT_ORIGINALS_DIR и OUTPUT_DATASET_DIR)

Скрипты генерации считают изображения из `/images/.../original/` и `/images/.../ground_truth_filters/` и перезапишут искаженные изображения в `/images/.../distorted/`

Запуск скриптов

```bash
python generate_dataset_noise.py
python presentation_generate_datasetcomp.py
python presentation_generate_datasetcomp_light.py
```
Дополнительных флагов или параметров запуска у скриптов нет, так как набор данных генерировался 1 раз

* `generate_dataset_noise.py`:
  Создает датасет исключительно для задачи шумоподавления (без смаза). Для каждого оригинального изображения генерируется 15 версий (5 типов $\times$ 3 уровня). Дополнительно строит scatter-plot распределения PSNR/SSIM.

  Использовался для `/compare_data/noise_1` и `/compare_data/noise`

* `presentation_generate_datasetcomp.py` (All-to-All):

  Генерирует полные матрицы искажений. Для каждой пары (Оригинал $\times$ Ядро) создается 6 версий:
  * 1 только смаз
  * 5 зашумленных версий (каждый из 5 типов шума, уровни чередуются)

  Использовался для `/compare_data/.../Grid_Test/`, `/compare_data/kostya/nonblind/`

* `presentation_generate_datasetcomp_light.py` (Light):

  Облегченная версия. Генерирует 4 варианта на пару (clean, weak, medium, strong) со смещением типов шума. Используется для экономии вычислительных ресурсов при тестировании

  Использовался для `/compare_data/.../Levin/`, `/compare_data/.../Kohler/`, `/compare_data/.../Sun/`, `/compare_data/.../Set12/`, `/compare_data/.../Lai/`(он не использовался в тестах, но он есть)

* Некоторые наборы были собраны вручную или точечно выбраны из других наборов. 
  К таким наборам относятся `/compare_data/.../Complexity_Test`, `/compare_data/.../log_test`, `/compare_data/.../param_grid_test` `/compare_data/kostya/priors/`
