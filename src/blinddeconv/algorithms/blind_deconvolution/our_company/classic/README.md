# Classic implementations

Этот раздел содержит «классические» (не обязательно байесовские) схемы слепой деконволюции: попеременную минимизацию, EM-подобные обновления и Richardson–Lucy.

Обозначения (типичные):

- `g` — наблюдаемое изображение, `f` — искомое резкое изображение, `h` — PSF/ядро.
- Модель: $g = h * f + n$ (для гауссова шума) или пуассоновская модель (для RL).

## `alternating_minimization.py` — `AlternatingMinimizationDeconv`: MAP с регуляризацией Хубера

**Математика**

Минимизируется MAP-функционал с робастной регуляризацией на градиент:

$
\min_{f,h} \|g - h \otimes f\|_2^2 + \lambda \, \rho(Df)
$

где `D` — дискретный градиент, `ρ` — функция Хубера (квадратичная около нуля и линейная на больших остатках). Оптимизация невыпуклая, поэтому используется попеременная минимизация:

1) фиксируем `f` и обновляем $h$ с ограничениями $h \ge 0$, $\sum h = 1$;
2) фиксируем `h` и обновляем `f` (шаг по `f` учитывает `ρ(Df)`).

**Как устроен код**

- Главный класс: `AlternatingMinimizationDeconv`.
- Свёртка и операторы решаются через FFT в `_convolve_fft(...)` (с отражающим паддингом и центровкой ядра через `ifftshift`).
- Регуляризация Хубера: `_huber_function(...)` и градиентный оператор из `_compute_gradient_operator()`.
- `process(...)` реализует внешний цикл: обновление ядра, затем обновление изображения, плюс трекинг истории (`self.history`).

## `expectation_maximization.py` — `EM`: EM-алгоритм для гауссовой модели

**Математика**

EM рассматривает $f$ как латентную переменную в модели $g = h * f + n$:

- **E-шаг**: оценивается апостериорное распределение $q(f) = \mathcal{N}(\mu_f,\Sigma_f)$ при текущих $h$, $\alpha$, $\beta$ (регуляризация изображения и точность шума). В частотной области это даёт «винеровские» формулы:
  - $\Sigma_f(k) = [\beta \, \mathbb{E}(|H(k)|^2) + \alpha |C(k)|^2]^{-1}$,
  - $\mu_f(k) = \beta \, \Sigma_f(k)\, H(k)^* G(k)$.
- **M-шаг**: обновляются параметры (например, `α`, `β`, `h`) из ожидаемых квадратов норм и ошибок реконструкции.

**Как устроен код**

- Главный класс: `EM`.
- E/M шаги вынесены в функции: `_e_step`, `_m_step_image_prior`, `_m_step_noise_precision`, `_m_step_blur`.
- Регуляризация SAR через спектр лапласиана: `_compute_laplacian_spectrum`.
- Представление ядра в FFT-формате: `_pad_kernel`, `_extract_kernel`.
- `process(...)` выполняет итерации EM и применяет проекцию/ограничения к `h` (неотрицательность/нормировка) после обновления.

## `richardson_lucy.py` — `RichardsonLucy`: слепой Richardson–Lucy (пуассоновский шум)

**Математика**

Классический RL максимизирует пуассоновское правдоподобие для неслепой задачи:

$
f^{t+1} = f^t \odot \left(h^T * \frac{g}{h * f^t}\right)
$

Слепая версия чередует обновления `f` и `h` (по сути, тот же мультипликативный вид, но по очереди).

**Как устроен код**

- Главный класс: `RichardsonLucy` (слепая версия) + `NonBlindRichardsonLucy` (не слепая).
- Внутренние операции свёртки/«деконволюции» реализованы частотными методами в `convolve(...)` и `deconvolve(...)` (с паддингом и `ifftshift`).
- `process(...)` реализует внешний цикл `iter`, где:
  - `m` раз обновляется ядро `g` (PSF),
  - `r` раз обновляется изображение `f`,
  - ядро нормируется $g = |g| / \sum |g|$.
